# اورا به‌عنوان اپلیکیشن نصب‌شدنی (PWA)

اورا یک **Progressive Web App** است؛ یعنی بدون نیاز به استور گوگل‌پلی یا اپ‌استور،
می‌توان آن را مثل یک اپ واقعی روی **گوشی اندروید، آیفون و دسکتاپ (ویندوز/مک/لینوکس)**
نصب کرد. نسخه نصب‌شده آیکون اختصاصی دارد، تمام‌صفحه و بدون نوار آدرس مرورگر باز
می‌شود و پس از نصب با یک کلیک اجرا می‌شود.

## روش نصب

### اندروید (Chrome / Edge / Samsung Internet)
1. سایت اورا را با مرورگر باز کنید.
2. از منوی سه‌نقطه گزینه **«افزودن به صفحه اصلی» / Install app** را بزنید.
3. یا اگر مرورگر، بنر نصب را نشان داد، روی آن بزنید و **نصب** را تأیید کنید.
4. آیکون اورا در صفحه اصلی گوشی ساخته می‌شود.

### آیفون و آیپد (Safari)
1. سایت را با Safari باز کنید (نصب PWA فقط از Safari ممکن است).
2. دکمه **Share** را بزنید.
3. گزینه **«Add to Home Screen»** را انتخاب کنید و تأیید کنید.

### دسکتاپ (Chrome / Edge)
1. سایت را باز کنید.
2. آیکون نصب (مانیتور با فلش) در سمت راست نوار آدرس را بزنید؛ یا از منوی
   سه‌نقطه، **«Install اورا (Overa)…» / Cast, save and share → Install page as app**
   را انتخاب کنید.
3. اپ در پنجره مستقل خودش اجرا می‌شود و در منوی استارت / داک قابل دسترسی است.

## جزئیات فنی

| مورد | مقدار |
|---|---|
| مانیفست | `/manifest.webmanifest` |
| سرویس‌ورکر | `/sw.js` |
| رنگ تم (نوار وضعیت/تایتل‌بار) | `#4c2a9e` |
| پس‌زمینه اسپلش | `#ffffff` |
| آیکون‌ها | `public/assets/img/pwa/` (192، 512، maskable-512، apple-touch 180) |

- مانیفست از طریق `metadata.manifest` در `src/app/layout.tsx` به صفحه متصل
  می‌شود و Next.js تگ `<link rel="manifest">` را رندر می‌کند.
- ثبت سرویس‌ورکر در کامپوننت `src/components/pwa/PWARegister.tsx` انجام
  می‌شود؛ این کامپوننت فقط روی HTTPS (یا localhost) ثبت را انجام می‌دهد و
  اگر مرورگر پشتیبانی نکند، بی‌صدا رد می‌شود — هیچ تأثیری روی کار عادی سایت
  ندارد.
- استراتژی کش سرویس‌ورکر عمداً محافظه‌کارانه است:
  - صفحات (navigation): اول شبکه، در قطعی اینترنت نسخه کش‌شده یا صفحه اصلی.
  - فایل‌های استاتیک (`/_next/static/`, `/assets/`, `/logo.svg`):
    stale-while-revalidate.
  - درخواست‌های `/api/`، متدهای غیر GET و دامنه‌های دیگر هرگز دخالت داده
    نمی‌شوند؛ پس داده‌های حساس یا پویا کش نمی‌شوند.

## تست محلی

```bash
bun run build && bun run start   # یا: bun run dev
# سپس در Chrome: DevTools → Application → Manifest → Installability
```

برای تست نصب روی گوشی، سایت باید روی HTTPS در دسترس باشد (مثلاً deploy روی
Vercel طبق `docs/DEPLOYMENT.md`).
