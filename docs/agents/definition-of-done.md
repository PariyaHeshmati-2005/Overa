# Definition of Done

A page/feature is done when:
- [ ] Route loads with no console errors.
- [ ] All copy is Persian; all numbers Persian digits.
- [ ] RTL correct; directional icons mirrored.
- [ ] Responsive at 1440/1024/768/390px (no overflow/overlap).
- [ ] Hover/focus/active/disabled/loading states present.
- [ ] No dead links; every button navigates or performs visible action.
- [ ] Uses tokens only (no hardcoded colors).
- [ ] Reuses shared components; no duplicates.
- [ ] lint + build pass.
- [ ] STATUS.md updated.
- [ ] Committed with conventional commit.
