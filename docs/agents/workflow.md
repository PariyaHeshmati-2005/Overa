# Agent Workflow

## Phases
0. Discovery (read-only) → 1. Docs scaffold + plan (stop for approval)
   → 2. Foundation → 3. Home → 4. Remaining pages (batches)
   → 5. Integration → 6. QA/polish → 7. Demo prep.

## Per phase
- Re-read relevant SKILL.md before work.
- Update `docs/progress/STATUS.md` after each phase.
- Commit per logical change (conventional commits).
- Verify: lint + build + browser at 4 widths.

## Definition of done (per page)
See `docs/agents/definition-of-done.md`.

## Handling ambiguity
Home page design is source of truth. Record conflicts in STATUS.md.
Ask user only when truly blocked.
